# 사다리 게임 - 1단계 사다리 출력

## 기능 요구사항

- 사다리는 4x4 크기로 고정한다.
- 가로 라인의 연결 여부는 랜덤으로 결정한다.
- 가로 라인이 겹치면 안 된다. (`|-----|-----|` 불가)

### 실행 결과

```
    |-----|     |-----|
    |     |-----|     |
    |-----|     |     |
    |     |-----|     |
```

## 구현할 기능 목록

### Point
- 연결여부 ----- boolean으로 판단하게 <- 이거 이야기하는 것

### BooleanGenerator
- RandomBooleanGenerator: 무작위로 `true`/`false`를 생성하게끔 함
- 테스트용으로도 쓰려고 인터페이스로 만들어서 주입하게끔 함

### Line
- Line은 가로 한줄을 의미하며, 칸과 각 칸의 연결여부를 담고있다.

### Ladder
- 지정한 높이만큼 `Line`을 생성한다.

### LadderSize
- 사다리의 높이/너비 숫자를 포장한다.

### 출력
- `LadderFormat` (Enum): 세로선 `|`, 연결 `-----`, 빈칸 `     `
- `OutputView`: 사다리를 실행 결과 형태로 출력한다. (맨 앞 4칸 공백)


# 사다리 게임 - 2단계 사다리 생성

## 기능 요구사항

- 사다리는 크기를 입력 받아 생성할 수 있다.
- 넓이는 세로줄 개수이고, 한 줄의 칸(`Point`)은 넓이 - 1개이다.
- 높이는 가로 줄(`Line`)의 개수이다.

### 실행 결과

```
사다리의 넓이는 몇 개인가요?
4

사다리의 높이는 몇 개인가요?
5

    |-----|     |-----|
    |     |-----|     |
    |-----|     |     |
    |     |-----|     |
    |-----|     |-----|
```

## 구현한 기능 목록

### Ladder
- 입력 받은 넓이(세로줄 개수)를 칸 개수(넓이 - 1)로 바꿔서 `Line`을 생성한다.

### 입력
- `InputView`: 넓이, 높이를 입력 받아 LadderSize 로 반환한다.
- `MessageFormat` (Enum): 입력 안내 문구를 모아둔다.

### 흐름
- `LadderController`: 입력 받은 크기로 사다리를 생성하고 출력한다.


# 사다리 게임 - 3단계 사다리 타기

## 기능 요구사항

- 사다리의 시작 지점과 도착 지점을 출력한다.

### 실행 결과

```
    |-----|     |-----|
    |     |-----|     |
    |-----|     |     |
    |     |-----|     |
    |-----|     |-----|

0 -> 0
1 -> 3
2 -> 2
3 -> 1
```

## 구현한 기능 목록

### Position
- 지금 서 있는 세로줄 번호를 감쌈
- 왼쪽이나 오른쪽으로 이동하면 새로운 Position을 만들어서 반환함

### Line
- move: 현재 위치의 왼쪽 칸이 연결이면 왼쪽, 오른쪽 칸이 연결이면 오른쪽으로 이동함
- 맨 왼쪽이나 맨 오른쪽은 없는 칸이라서 그쪽으로는 이동하지 않음

### Ladder
- climb: 출발 위치 하나를 모든 줄에 차례대로 통과시켜서 도착 위치를 반환함
- startPositions: 출발 가능한 위치들을 반환함 (세로줄 개수 = 칸 개수 + 1)

### LadderGame
- 모든 출발 위치로 사다리를 타서 도착 위치를 모음

### LadderResult
- 출발 위치별 도착 위치를 담고 있음 (인덱스 = 출발, 값 = 도착)

### 출력
- OutputView: 출발 -> 도착 형태로 출력함


# 사다리 게임 - 4단계 게임 실행

## 기능 요구사항

- 참여자에게 이름을 최대 5글자까지 부여할 수 있다.
- 사람 이름은 쉼표(,)를 기준으로 구분한다.
- 실행 결과도 쉼표(,)를 기준으로 구분하여 입력 받는다.
- 사다리를 출력할 때 사람 이름과 실행 결과도 같이 출력한다.
- 개인별 이름을 입력하면 개인별 결과를, "all"을 입력하면 전체 참여자의 결과를 출력한다.
- 사다리 넓이는 참여자 수로 정해진다.

### 실행 결과

```
참여할 사람 이름을 입력하세요. (이름은 쉼표(,)로 구분하세요)
neo,brown,brie,tommy

실행 결과를 입력하세요. (결과는 쉼표(,)로 구분하세요)
꽝,5000,꽝,3000

최대 사다리 높이는 몇 개인가요?
5

사다리 결과

  neo brown brie  tommy
    |-----|     |-----|
    |     |-----|     |
    |-----|     |     |
    |     |-----|     |
    |-----|     |-----|
    꽝 5000      꽝 3000

결과를 보고 싶은 사람은?
neo

실행 결과
꽝

결과를 보고 싶은 사람은?
all

실행 결과
neo : 꽝
brown : 3000
brie : 꽝
tommy : 5000
```

## 구현한 기능 목록

### Name, Names
- Name: 이름 하나를 감싸기, 최대 5글자
- Names: 쉼표로 구분한 이름들을 xhxh통으로 담기

### Prize, Prizes
- Prize: 실행 결과 하나를 감쌈 (꽝, 5000)
- Prizes: 쉼표로 구분한 실행 결과들을 통째 담기

### PlayerPrize, PlayerPrizes
- PlayerPrize: 참여자 이름과 그 참여자가 얻은 결과 묶어둔거
- PlayerPrizes: 사다리 타고 내려간 도착 위치에 해당하는 결과를 참여자에게 짝지어서 담고 있음

### 입력
- InputView: 이름, 실행 결과, 높이, 결과를 보고 싶은 사람을 입력 받음
- MessageFormat: 문구를 모아둠

### 출력
- OutputView: 사다리 위에 이름, 아래에 실행 결과를 같이 출력함
- 이름을 입력하면 개인 결과, all 을 입력하면 전체 결과를 출력함

### 흐름
- LadderController: 이름, 실행 결과, 높이를 입력 받아 사다리를 만들고(넓이는 참여자 수) 출력함
- 결과를 보고 싶은 사람을 입력 받아 개인 결과를 보여주고, all 이 입력되면 전체 결과를 보여주고 끝냄
