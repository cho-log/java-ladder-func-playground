# 🪜 Java 사다리 

## 1단계 - 사다리 출력
### `Line` 객체
- 사다리 가로 한 줄을 담당
- 랜덤하게 연결 상태를 생성
- 리스트가 비어 있는 경우 -> 다음 값을 랜덤으로 생성
- 직전 값이 true인 경우 -> 다음 값은 false만 가능
- 직접 값이 false인 경우 -> 다음 값을 랜덤으로 생성

### `Ladder` 객체
- `Line` 여러개를 관리

### `LadderOutputView`
- `Ladder` 객체를 받아서 문자열로 변환
- 문자열로 변환된 사다리 출력

## 2단계 - 사다리 생성
### `Width`
- 사다리 넓이 값을 담당
- 최소값은 2이다. 세로줄이 최소 2개 있어야 가로줄을 연결할 수 있기 때문이다.

### `Height`
- 사다리 높이 값을 담당
- 최소값은 1이다. 사다리는 최소 1개의 행으로 구성되어야 하기 때문이다.

### `InputView`
- 사다리 넓이, 높이 값을 입력받는다.

### `OutputView`
- 프로그램 출력을 담당한다.

### `LadderController`
- 프로그램의 흐름을 관리한다.
