# 🪜 사다리 게임
참가자 이름과 실행 결과를 입력하면 랜덤으로 사다리를 만들고, 각 참가자가 어떤 결과를 받는지 보여줍니다.


## 기능 목록

### 입력
- [x] 참가자 이름을 쉼표(,)로 구분해 입력받는다
- [x] 실행 결과를 쉼표(,)로 구분해 입력받는다
- [x] 사다리 높이를 입력받는다
- [x] 결과를 볼 참가자 이름을 입력받는다 (`all`이면 전체)

### 사다리 생성
- [x] 참가자 수 - 1 개의 다리 자리를 가진 한 줄(Line)을 만든다
- [x] 다리는 랜덤으로 놓는다
- [x] 가로 다리가 연속으로 붙지 않게 한다 (`|-----|-----|` 금지)
- [x] 입력한 높이만큼 줄을 쌓아 사다리(Ladder)를 만든다

### 사다리 타기
- [x] 한 줄에서 왼쪽에 다리가 있으면 왼쪽, 오른쪽에 있으면 오른쪽으로 이동한다
- [x] 모든 줄을 위에서 아래로 따라가 도착 위치를 구한다
- [x] 참가자 이름과 도착 위치의 실행 결과를 매핑한다

### 출력
- [x] 참가자 이름, 사다리, 실행 결과를 칸에 맞춰 출력한다
- [x] 한 사람 또는 전체 참가자의 결과를 출력한다

### 예외 처리
- [x] 이름이 비어 있거나 5자를 넘으면 예외
- [x] 참가자 이름이 중복되면 예외
- [x] 실행 결과가 비어 있으면 예외
- [x] 실행 결과 개수가 참가자 수와 다르면 예외
- [x] 높이에 숫자가 아닌 값을 입력하면 예외
- [x] 존재하지 않는 참가자의 결과를 조회하면 예외

## 패키지 구조

```
src/main/java
├── LadderMain.java              # 실행 진입점
├── controller
│   └── LadderController.java    # 입력 → 도메인 → 출력 흐름 연결
├── model
│   ├── Name.java                # 참가자 이름 (원시값 포장)
│   ├── Names.java               # 참가자 목록 (일급 컬렉션, 중복 검증)
│   ├── Prize.java               # 실행 결과 (원시값 포장)
│   ├── Prizes.java              # 실행 결과 목록 (일급 컬렉션, 개수 검증)
│   ├── Line.java                # 사다리 한 줄, 다리 생성과 이동
│   ├── Ladder.java              # Line들의 모음, 사다리 타기
│   ├── LadderResult.java        # 참가자 → 실행 결과 매핑
│   └── generator
│       ├── PointGenerator.java        # 다리 생성 전략 (함수형 인터페이스)
│       └── RandomPointGenerator.java  # 랜덤 다리 생성
└── view
    ├── InputView.java
    ├── OutputView.java
    └── PointShape.java          # 다리 출력 모양 (enum)
```
