# 사다리 게임 - 1단계 사다리 출력

## 기능 요구사항

- 사다리는 4x4 크기로 고정한다.
- 가로 라인의 연결 여부는 랜덤으로 결정한다.
- 가로 라인이 겹치면 안 된다. (`|-----|-----|` 불가)

### 실행 결과

```
    |-----|     |-----|
    |     |-----|     |
    |-----|     |     |
    |     |-----|     |
```

## 구현할 기능 목록

### Point
- 연결여부 ----- boolean으로 판단하게 <- 이거 이야기하는 것

### BooleanGenerator
- RandomBooleanGenerator: 무작위로 `true`/`false`를 생성하게끔 함
- 테스트용으로도 쓰려고 인터페이스로 만들어서 주입하게끔 함

### Line
- Line은 가로 한줄을 의미하며, 칸과 각 칸의 연결여부를 담고있다.

### Ladder
- 지정한 높이만큼 `Line`을 생성한다.

### LadderSize
- 사다리의 높이/너비 숫자를 포장한다.

### 출력
- `LadderSymbol` (Enum): 세로선 `|`, 연결 `-----`, 빈칸 `     `
- `OutputView`: 사다리를 실행 결과 형태로 출력한다. (맨 앞 4칸 공백)
